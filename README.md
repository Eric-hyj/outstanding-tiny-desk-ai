# Outstanding Tiny Desk AI Generator

Product website: [Outstanding Tiny Desk AI Generator](https://outstandingtinydesk-ai.com)

This repository contains a public product introduction only. It does not contain the commercial application's source code, user photos, generated private videos, or credentials.

## Current status

A browse-only Cloudflare preview is available at [the preview website](https://outstanding-tiny-desk-ai.539965687.workers.dev). The planned custom domain above is not connected. Sign-in, server uploads, purchases, and generation are disabled in this preview; the new site has not completed production integration testing.

## Planned experience

- Upload one authorized photo for the lead vocalist.
- Add a second authorized photo to cast the saxophone player.
- Create a 19-second, vertical desk-concert video with 480p or 720p quality options.
- Follow generation progress, then view and download the result in your account.

The implementation reuses the existing operator's desk-concert workflow. Outcome quality, resemblance, and timing can vary. This new website has not yet completed its own real-generation acceptance test.

## Before uploading

Use photos you own or have permission to use. Review the website's pricing, privacy information, and service terms when it launches. This is an independent AI tool, not an official NPR or Tiny Desk service.
