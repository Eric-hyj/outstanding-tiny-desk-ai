## Current status

The website is live at [outstandingtinydesk-ai.com](https://outstandingtinydesk-ai.com). The Cloudflare default address remains available as a noindex fallback. Google sign-in, private uploads, generation, and checkout integrations are enabled, with an independent database and private media storage. Configuration and no-charge checks have passed; real paid generation and payment acceptance have not been tested for this new site.

## Workflow

- Upload one authorized photo for the lead vocalist.
- Add a second authorized photo to cast the saxophone player.
- Create a 19-second, vertical desk-concert video with 480p or 720p quality options.
- Follow generation progress, then view and download the result in your account.

The implementation reuses the existing operator's desk-concert workflow. Outcome quality, resemblance, and timing can vary. This new website has not yet completed its own real-generation acceptance test.

## Before uploading

Use photos you own or have permission to use. Review the website's pricing, privacy information, and service terms before using it. This is an independent AI tool, not an official NPR or Tiny Desk service.
